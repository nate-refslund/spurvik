1. Never log raw user prompts or personal data to `console.log` or plaintext tables (GDPR Art. 5(1)(c)); wrap model clients with `@spurvik/sdk` (`spurvik.wrap(...)`) to emit chained HMAC-SHA256 digests with no raw prompt text persisted (supporting EU AI Act Art. 12).
2. Ensure user-facing AI chat/assistant UIs render an EU AI Act Art. 50(1) AI interaction notice badge.
3. Place a deterministic pre-flight `ask_human` gate (supporting EU AI Act Art. 14) in front of any agent tool that moves money, modifies contracts/permissions, deletes data, or sends external messages.
4. **Founder Business, Market & User-Value Mindset (Mandatory on All Product, Console, Web & Content Work)**:
   - **5-Second Buyer Value Test**: Every screen must deliver immediate, personal, interactive value to a cold visitor (vibe-coder, developer, or founder) within 5 seconds without reading paragraphs or code blocks. Always ask: *"Why would a user care about this screen, and what makes them want to upgrade from Free (€0) to Pro (€19/mo)?"*

   - **Mandatory Vision Screenshot Self-Test**: Never report any UI or visual asset as complete based only on DOM/CSS scripts or unit tests; always capture a real browser screenshot, inspect it visually with `read_file`, and fix any visual, UX, or value weakness before presenting to the founder.
